# Welcome Bot — Apple Release Monitor

Состояние на 27 октября 2026: монитор включён на VPS в действующем bridge; публикация включена в существующую группу уведомлений Technology Universe 🔒 по указанию владельца. При первом запуске зафиксированы 29 исторических записей без их публикации. Интервал опроса 900 секунд; объединение — 1800 секунд. Тестовая обложка, созданная генератором, отправлена администратору отдельно, Telegram подтвердил message_id 82. Новый реальный релиз после включения пока не наблюдался.

## Управление

Команды в личном чате доступны только ADMIN_IDS: `/apple`, `/apple_status`, `/apple_check`, `/apple_monitor_on`, `/apple_monitor_off`, `/apple_interval 900`, `/apple_recent`, `/apple_history`, `/apple_test`, `/apple_autopublish_on`, `/apple_autopublish_off`, `/apple_wallpapers`, `/apple_wallpaper_add`, `/apple_wallpaper_approve`. Для добавления отправить файл с подписью `/apple_wallpaper_add iOS 27 https://developer.apple.com/... | сведения о правах`. Система ограничивает размеры файлов, сохраняет SHA-256 и ждёт подтверждения. Команда подтверждения: `/apple_wallpaper_approve ПОЛНЫЙ_SHA256`.

## Ограничения

- Источник — официальный RSS Apple Developer; опубликованы только записи, соответствующие строгим шаблонам. Не гарантируется обнаружение HomePod или нестандартных экстренных выпусков, если они не представлены в этом RSS.
- Подробные изменения и индивидуальную доступность релиза модуль пока не извлекает: текст честно сообщает, что список изменений не подготовлен.
- Экран использует проверенное изображение из библиотеки либо нейтральный фон. Автоматического скачивания новых обоев и проверки прав нет. Материалы Apple Newsroom для локального макета не перенесены в библиотеку без подтверждения прав.
- Вырезка устройств и маски приблизительные, видны артефакты на отдельных краях; отсутствуют отдельные маски для Apple TV и Vision Pro. Оригиналы сохранены.
- При слишком длинной подписи, ошибке рендера или неоднозначной доставке публикация переводится на ручную проверку; автоматического текстового fallback нет. При подтверждённом отказе Telegram запись помечается failed. Неоднозначные отправки не повторяются автоматически.
- Передача новой новости в группу через работающий модуль ещё не проверена в реальном событии. Не добавлять тестовые релизы в основной чат. Изменение адреса: APPLE_RELEASE_CHANNEL_ID, по умолчанию существующий STORAGE_NOTIFICATION_CHAT_ID.
- Данные хранятся в /data/apple-releases.sqlite3; каталог изображений /data/apple-release-assets. Не удалять их при обновлении или переносе.
- Автоматические тесты проверяют парсинг и безопасные сценарии, но не заменяют проверку всех сетевых сбоев и работу после рестарта с реальной доставкой.
